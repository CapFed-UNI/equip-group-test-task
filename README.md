# Тестовое задание на позицию PHP программист (full-stack)

## Каталог интернет-магазина
> Заданию уделите от 5 до 24 рабочих часов, что успеете высылайте. Срок 5 дней.

### Вводные данные
*	Дан каталог товаров;
*	Каждый товар имеет атрибуты:
    * название;
    * цена;
    * группа.
* Количество уровней каталога - неограниченно;
* Добавление новых полей в таблицы недопустимо;
* Информация о товарах, группах и ценах находится в приложенном дампе базы [test.sql](https://bitbucket.org/EquipGroupRu/php-programmist-full-stack/src/a17e5a4a18d8/test.sql) данных MySQL, содержащий две таблицы:
    * **groups** – таблица групп товаров, содержит поля:
        * id – идентификатор группы
        * id_parent – идентификатор «родительской» группы
        * name – название группы
    * **products** – таблица товаров, содержит поля:
        * id – идентификатор товара
        * id_group – идентификатор группы товаров
        * name – название товара
    * **prices** – таблица цен, содержит поля:
        * id – идентификатор товара
        * id_product – идентификатор товара
        * price – цена товара

### Задача
- При запуске должен выводиться список (url) групп товаров первого уровня (groups.id_parent=0), список всех товаров (url) а также пагинация и сортировка по цене (возрастание/убывание) и по названию (возрастание/убывание);
- Возле названия группы должно быть написано общее количество товаров в группе (количество товаров в самой группе и во всех ее подгруппах);
- При переходе по ссылке (выборе группы товаров первого уровня) – кроме списка групп товаров первого уровня выводится также список всех подгрупп выбранной группы, все имена подгрупп также являются ссылками, и возле названия подгруппы находится количество товаров, содержащихся в этой подгруппе. Также выводятся все товары, отнесенные к выбранной группе (и всем ее подгруппам). Сортировка и пагинация работает уже с товарами выбранной группы и товарами, находящимися в её подгруппах;
- Каждый товар выводится с названием и ценой. При переходе по ссылке товара (название товара) – выводится карточка товара;
- Карточка товара должна содержать в себе название товара, цену товара, хлебные крошки (включая родительскую группу товара);

### Требования

> Если есть сомнения по деталям — решение принять самостоятельно, но в своём README.md рекомендуем выписать вопросы и принятые решения по ним.

* Язык программирования PHP; Фреймворк – Laravel;
* Финальную версию нужно выложить на github.com / bitbucket.org;
* Предоставить инструкцию по запуску приложения. В идеале (но не обязательно) – использовать контейнеризацию с возможностью запустить проект командой docker-compose up;
* В идеале (но не обязательно) – во внешнем виде использовать bootstrap.

### Усложнения

> Не обязательно, но задание может быть выполнено с любым числом усложнений:

* Внешний вид HTML: bootstrap;
* Возможность поменять количество товаров на одной странице с 6 на 12, 18;
* Контейнеризация: есть возможность поднять проект с помощью команды docker-compose up;
* Присутствуют миграции и сиды (используя Faker для генерации данных);
* Архитектура сервиса описана в виде текста и/или диаграмм;
* Документация: есть структурированное описание методов сервиса;
* Юнит тесты: постарайтесь достичь покрытия в 70% и больше;
* Сортировка в каталоге и/или пагинация происходит по AJAX.
